# 进销存管理系统

采购 → 库存 → 成本 → 付款 全流程管理系统

## 技术栈

- **后端**: Node.js + Express
- **数据库**: SQLite (better-sqlite3) — 本地开发无需安装数据库
- **前端**: 单 HTML + app.js (原生 JS)
- **依赖库**: XLSX.js (Excel导入导出), Chart.js (图表)

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（可选，有默认值）
cp .env.example .env

# 3. 启动服务
npm start

# 4. 访问系统
# 浏览器打开 http://localhost:3001?admin
# 默认账号: admin / admin
```

## 业务流程

```
采购建议 → PO → PI → CI/PL → 物流 → 入库 → 成本分摊 → 库存更新 → 付款审批
```

### 核心计算逻辑

- **定金**: 基于 PI 总金额 × 定金比例
- **定金抵扣**: CI 发货时按比例抵扣，min(发货金额×定金比例, 可用定金)
- **尾款**: CI 货值 - 定金抵扣额
- **运费分摊**: 海运按 CBM，空运按重量
- **关税分摊**: 按商品金额比例
- **加权平均成本**: (入库前库存×入库前成本 + 本次入库量×本次单位成本) ÷ 总量

## 权限模型

- 角色 + 权限码，通过 Header 传递 (X-User-Id, X-User-Role, X-User-Permissions)
- 三级角色: 超级管理员 / 操作员 / 查看者
- 50+ 权限码覆盖所有业务操作

## 审批流

- 多级审批 (approval_records 表记录历史)
- 支持: PO审批、定金付款、尾款付款、运费付款、关税付款、盘点差异、报废

## 功能模块

1. 首页看板 (库存价值、在途、呆滞、应付账款)
2. SKU 主数据 (批量导入/导出)
3. 库存管理 (导入/总表/出库)
4. 补货建议 (周转月数计算)
5. PO 管理 (创建/审批/发工厂/导出)
6. PI 管理 (定金计算)
7. CI/PL 管理 (定金抵扣)
8. 物流管理 (运费/关税)
9. 入库管理 (触发成本分摊)
10. 成本管理 (分摊明细/加权平均)
11. 付款管理 (定金/尾款/运费/关税)
12. 库存盘点 (模板/导入/审批)
13. 呆滞分析
14. 货代分析
15. 系统管理 (国家/仓库/供应商/货代/币种/汇率/付款条件/审批流/费用类型/分摊规则/配置/用户/角色)
