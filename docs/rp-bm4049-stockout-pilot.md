# BM4049 断货影响试点｜订单预测复盘报告

范围：仅 BM4049 型号（系统 SKU 代码或 SKU 主档 model 包含 BM4049），不扩大至其他型号。

## 数据流
- 已有订单预测页面只读快照 → 用户点击“生成库存周转复盘报告”。
- 只有命中 BM4049 时才发起一组 read-only /api/replenishment-suggestions/stockout-evidence 查询，按 SKU/国家/目标仓库隔离；最多 4 个组合。
- 接口要求 replenishment_view + inventory_view；按订单预测数据范围过滤；销量另按销售数据权限过滤。
- 查近 120 天 `inventory_imports` 实际库存快照（日期及可用库存）和 `sales_records` 有效订单逐日销量。
- 后端输出可追溯的观察天数、零库存日、首个补货后正库存快照、补货前后销量及参考需求。

## 禁止推断
1. `inventory_imports.import_date` 是库存观察日，不是逐日流水。不能从一条零库存记录推定下一个快照前的每一天都断货。
2. 国家级销售与单仓库存不可强行对齐：同国多仓时仅提示证据，不计算参考需求、不移出高库存。
3. 零库存当天仍有销量时，可能是日终快照，定量计算不可信。
4. 稀疏库存历史不能据“0销量”填造“0库存”。
5. 检验前/中/后销量：补货前有销量、观测零库存区间销量低、补货后恢复销量，才允许判断为“断货影响待复核”。

## 结论等级
- `qualified`：至少 80% 的日库存快照覆盖、21 个可售库存观测日、两个零库存观测日、有补货后快照、有销量恢复证据、无同日矛盾、非多仓。仅可计算 **参考** 月需求 = 有正库存快照日期内有效销量 / 正库存观测天数 ×30；不得改系统月均、采购建议。
- `stockout_observed`：有零库存记录、后续有正库存记录，但不满足定量门槛。若销量恢复证据齐全且非多仓，则原本被判高库存的试点型号进“断货影响待复核”，不是“周转正常”。
- `zero_observed` / `insufficient`：只展示已知情况，原库存分类不变。
- `unavailable`：权限或 API 出错，只显示错误，原库存分类不变。
- 即使是 `qualified`，调整参考周转仍高于目标时，保留高库存标签。

## 2026-10-16 RDBM4049 真实数据验收与观察期补充
- 印尼 Bekasi Warehouse：2026-07-05 库存 344 → 07-31 库存 60；8 月、9 月多次观察到零库存；2026-10-08 库存 4 → 10-15 库存 1615；最新的 last_inbound_date 为 2026-10-13。
- 最近 120 天仅 14 个不同日期库存快照，其中 7 个日期为零。不能估算精确断货天数、也不能把 344/月自动当成恢复后的真实月需求。
- 旧状态 `stockout_observed` 的销量恢复阈值因大批货刚到 3 天而未满足，故旧版报告仍列“严重高库存”，并非 SKU 映射出错。
- 新增 `recentMajorRestock` **展示型证据**：最新快照含有效的最近 14 天 last_inbound_date，入库日期晚于最近一个零库存日、晚于上次库存观察日，且最近正库存大于等于原观察库存 5 倍、净观察差额不少于 100、至少 2 个已观察零库存日、没有零库存当天订单矛盾、没有同国多仓口径冲突。
- 命中后，仅在复盘报告内将试点型号从确定性“高库存”移到“断货后近期大批补货 · 观察期”，同时保留原周转 20.7 月、原销量 78 件/月、后端原 `risk_tags`、采购建议 0 和 blocked。
- 快照 4 → 1615 是两个时点的**观察差额 1611**，并非实际入库数量。观察期 14 天结束后如无其他合格证据，恢复原高库存分类；不允许无限延长观察。
- 补货后有效日销量样本不足时，`referenceMonthlyDemand` 与 `referenceTurnover` 继续为空，不臆造“调整后周转”。
- 此补充只作用于 BM4049 试点，不推广到其他 SKU。

## 改动红线
- 不写入或更新生产数据、历史库存、历史销量、SKU 主档。
- 不改变 4 个月销量、目标周转、库存池、预测、blocked、建议采购数量。
- 不在页面首载、普通筛选、线上/线下 Tab 切换增加任何网络请求。
- 报告、复制和 Excel 用同一份增强后的纯 DTO；非 BM4049 保持原样。
- 生产 BM4049 真实日销量 / 历史库存尚未完成授权登录态验收；不得以测试夹具当作真实销量或断货天数。
