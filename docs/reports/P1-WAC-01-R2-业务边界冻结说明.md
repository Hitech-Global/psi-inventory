## 一、冻结业务前提（10 条，作为 P1-WAC 后续设计的强制前提）

以下规则自本说明起**冻结**，P1-WAC-02 及后续所有设计任务必须以此为前提简化模型，不得预留跨国家复杂能力。

1. **一张 CI 只对应一个库存国家。**
2. **一张 CI 下的所有成本和费用均归属于同一个库存国家。**
3. **一笔费用不得跨国家分摊。**
4. **同一 CI 的目标本国货币唯一，由该 CI 对应库存国家确定：**
   - 印度尼西亚 → IDR
   - 马来西亚 → MYR
   - 泰国 → THB
5. **同一 CI 下所有参与 WAC 的成本来源，必须先按照各自冻结的汇率日期和 rate_type，分别换算为该国家本国货币。**
6. **所有成本完成本币换算后，再在该国家内部按 SKU / 仓库进行成本分摊。**
7. **本币分摊总额必须守恒，尾差按照后续冻结的精度与尾差规则处理。**
8. **不需要设计"一笔费用跨多个国家拆分后分别换汇"的模型。**
9. **不需要为当前业务设计多目标国家费用分配关系。**
10. **若未来业务需支持跨国家 CI 或跨国家费用分摊，必须作为新的独立能力重新设计，不得在本轮预留复杂模型或顺带实现。**

## 二、对前述设计边界的同步修正

### 2.1 删除"多目标国家时先拆分原币金额、再分别换算"的业务设计要求
- 在 R1 §四（换算与分摊顺序）的对比分析中，曾列出"同一费用分到不同国家：需先按国家归属拆分成本或按国家分别换算"作为候选处理。
- **现予删除**：当前业务保证单一国家（前提 1–3），不存在一笔费用跨多国家的场景，故该拆分-分别换算路径**不是当前业务设计要求**，不进入 P1-WAC 模型。
- R1 推荐的"甲：先换算成本国货币、再分摊"在**单一国家内部**继续有效，不受本条删除影响。

### 2.2 保留"禁止费用跨国家分摊"的后端校验设计项
- 尽管当前业务不发生跨国家分摊，仍**保留**一条防御性后端校验（设计项，非实现）：当系统检测到某笔费用被尝试分配到非 CI 目标国家时，拒绝并告警。
- 该校验属 P1-WAC 实施后的健壮性防护，不构建跨国家分配数据模型（呼应前提 3、8、9、10）。

### 2.3 P1-WAC-02 范围收窄
- P1-WAC-02（成本来源与币种事实模型冻结）**只需处理单一国家下，多 SKU、多仓库的成本来源与分摊模型**。
- 不再要求 P1-WAC-02 设计跨国家成本归属、跨国拆分、多目标货币费用关系。
- 国家映射键归一化（解决 `印尼` vs `印度尼西亚`）仍属 P1-WAC-02 范围（单国家内键统一）。

### 2.4 汇率快照仍须按每笔成本来源独立锁定
- 即使同一 CI 目标国家唯一、目标本币唯一，**汇率快照仍须按每笔成本来源独立锁定**。
- 理由：不同费用可能具有不同的**原币、付款日期、rate_type、rate_source**（如 USD 货款用成本结算锚点、USD 国际运费用运费付款日、IDR 本地费用用本地费付款日），其汇率事实不可合并为单一快照。
- 与 R1 §三推荐设计一致：费用级为最小不可变单元，去重 upsert 仅作用于"完全相同 (source, target, rate_type, rate_date, rate_source)" 的组合。

### 2.5 wac_history 不得简化为单一 snapshot_id
- 一条 `wac_history` 仍可能关联**多笔成本来源**与**多个汇率快照**（如同一 CI 含货款 + 国际运费 + 本地费用，各自独立快照）。
- 因此 `wac_history` **不得简化成只保存一个 `exchange_rate_snapshot_id`**；须保留 `snapshot_ids` 列表（或等价多引用）以承载多成本来源的汇率证据。
- 与 R1 §三、§七一致：wac_history 保存不可变汇率事实**引用**，不重复存原始汇率。

### 2.6 推荐统一流程（冻结）
以下流程作为 P1-WAC 实施的标准链路：

```
成本来源
  → 确定 CI 唯一目标国家
  → 确定唯一目标本国货币（IDR / MYR / THB）
  → 每笔成本按各自冻结规则换算为本币（独立汇率快照锁定）
  → 汇总本币成本
  → 在该国家内部按 SKU / 仓库分摊
  → 计算本币 WAC
  → 生成并锁定 wac_history（含汇率证据引用）
  → ERP 最新库存导入时再投影 inventory 三字段
```

- 全程不读取/不混入其他国家的成本与汇率。
- 人民币仅派生，不进入上述本币 WAC 链（沿用 Final V1.0 与 P1-03 冻结基线）。
