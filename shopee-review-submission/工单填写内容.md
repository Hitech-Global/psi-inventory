```
Dear Shopee Open Platform Support,

We are trying to read our own store's natural traffic and conversion figures
(visitors, page views, clicks, add-to-cart, orders and conversion rates) through
the Open Platform, from our ERP System application (Partner ID 2045604,
App Category: ERP System, App Status: Online).

We could not find the endpoint in the public API reference. The only endpoint we
could find under the Business Insights module is

  GET /api/v2/business_insights/get_marketing_hot_listing

That one is accepted by our partner - it answers with a parameter error, which
tells us the endpoint exists for us:

  {"code":10006,"msg":"err:invalid param, detail:invalid country header, country="}

and it names its parameters as StartTime / EndTime / Period, plus a country
header - which suggests the Business Insights endpoints are the brand-level
(BR) ones.

The three paths we need return "error_not_found", which appears to mean the
endpoint is not there rather than that we lack permission:

  GET /api/v2/business_insights/get_shop_traffic          -> {"error":"error_not_found"}
  GET /api/v2/business_insights/get_shop_performance      -> {"error":"error_not_found"}
  GET /api/v2/business_insights/get_product_traffic       -> {"error":"error_not_found"}

Other endpoints under the same partner work normally, so this is not a
signing, token or shop-authorisation problem on our side:

  GET /api/v2/business_insights/get_marketing_hot_listing  -> reached (parameter error)
  GET /api/v2/account_health/get_shop_performance          -> success
  GET /api/v2/shop/get_shop_info                           -> success
  GET /api/v2/shop/get_shop_notification                   -> success

A copy of one failing request:

  GET https://partner.shopeemobile.com/api/v2/business_insights/get_shop_traffic
      ?partner_id=2045604
      &timestamp=1793801154
      &access_token=<masked>
      &shop_id=1326456001
      &start_date=2026-10-01
      &end_date=2026-10-07
      &sign=4b0d462d0e3be0932c103e33c2841bafae6d5861824219c35599fd92444875d3

  Response: {"error":"error_not_found"}

Could you please advise:

1. What is the correct Open API path for the traffic and conversion figures of
   a single shop - visitors, page views, clicks, add-to-cart, orders and
   conversion rates?
2. If the Business Insights endpoints are the brand-level ones, is a principal
   (Brand Portal) authorisation required to read them for a single shop, and
   if so which endpoint should we call afterwards?
3. If the figures are only available through the seller centre export, please
   confirm that, so that we can stop looking for an endpoint that is not there.

Why we need it: our application is an internal analytics dashboard for our own
Shopee stores, and we report the traffic and conversion figures daily. These
are the store's own figures, not advertising figures - advertising data is
already read through our separate Ads Service application.

Thank you.
```
