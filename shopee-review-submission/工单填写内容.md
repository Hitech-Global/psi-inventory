## Question Description（复制）

```
Dear Shopee Open Platform Support,

We are trying to read our own store's natural traffic and conversion figures
(visitors, product clicks, add-to-cart, orders, conversion rate and sales)
through the Open Platform, from our ERP System application (Partner ID 2045604,
App Category: ERP System, App Status: Online).

We understand that these figures come from the Business Insights permission pool
of an ERP System application, and that a Brand Portal application does not give
a single shop's own figures. Our application answers:

  POST /api/v2/business_insights/get_marketing_overview
      body: {"date_start":"2026-10-01","date_end":"2026-10-31"}

  Response: {"error":"error_not_found"}

while other endpoints under the same partner work normally:

  GET  /api/v2/account_health/get_shop_performance          -> success
  GET  /api/v2/shop/get_shop_info                           -> success
  GET  /api/v2/shop/get_shop_notification                   -> success
  GET  /api/v2/top_picks/get_top_picks_list                 -> success
  GET  /api/v2/public/get_shops_by_partner                  -> success
  GET  /api/v2/push/get_push_config                         -> success
  GET  /api/v2/business_insights/get_marketing_hot_listing   -> reached (parameter error)

The application was created before the API Permission section existed in the
console, so there is no place for us to turn the Business Insights permission
pool on for it - the App details page shows only the App Category, the App
Description, the redirect URL domain and the declarations.

Could you please advise:

1. Can the Business Insights permission pool be turned on for this existing
   application (Partner ID 2045604), and if so, how? A ticket to our account
   manager would also be fine.
2. If it cannot be turned on for an existing application, please confirm that
   we should create a new application of the ERP System type with the Business
   Insights permission pool enabled, and we will do that.
3. Please also confirm that a Brand Portal application is not able to read a
   single shop's own traffic figures, so that we do not go down that road.

Why we need it: our application is an internal analytics dashboard for our own
Shopee stores, and we report the traffic and conversion figures daily. These
are the store's own figures, not advertising figures - advertising data is
already read through our separate Ads Service application.

Thank you.
```
