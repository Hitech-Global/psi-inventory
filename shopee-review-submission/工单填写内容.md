  GET /api/v2/business_insights/get_marketing_hot_listing   (works with our partner)

  GET /api/v2/business_insights/get_product_traffic

Other endpoints under the same partner work normally, so this is not a
signing, token or shop-authorisation problem on our side:

  GET /api/v2/business_insights/get_marketing_hot_listing   -> success
  GET /api/v2/account_health/get_shop_performance           -> success
  GET /api/v2/shop/get_shop_info                            -> success

A copy of one failing request:

  GET https://partner.shopeemobile.com/api/v2/business_insights/get_shop_traffic
      ?partner_id=2045604
      &timestamp=1793801154
      &access_token=<masked>
      &shop_id=1326456001
      &start_date=2026-10-01
      &end_date=2026-10-07
      &sign=4b0d462d0e3be0932c103e33c2841bafae6d5861824219c35599fd92444875d3

  Response: {"error":"error_not_found"}

Could you please advise:

1. What is the correct Open API path for the traffic and conversion figures of

   conversion rates)?
2. Which application type is required to call it? We understand that an ERP
